#### بخش بکند:
1. پیشنیاز ها را با دستور زیر نصب کنید:
``` bash
pip install -r requirements.txt
```
2. فایل .env خود را از .env.example بسازید
3. با دستور زیر، بکند را اجرا کنید:
``` bash
uvicorn app.main:app --reload
```
